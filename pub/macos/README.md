# SpacePenguin for macOS

**Version 1.0.0-rc.7** (release candidate), from [SpacePenguin's release](https://github.com/developer1-vd/SpacePenguin/releases/tag/v1.0.0-rc.7).

Open the disk image and drag SpacePenguin to Applications. It is not notarised yet, so the first start needs *System Settings › Privacy & Security › Open Anyway*. Or with Homebrew: `brew tap developer1-vd/spacepenguin && brew trust developer1-vd/spacepenguin && brew install --cask spacepenguin`.
